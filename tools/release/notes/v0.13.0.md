## Words on icons, and more to draw them with

This release brings bam up to [isolex](https://forge.axonibyte.com/axonibyte/isolex) 0.5.0. Icons can now carry words, including each asset's own name, code or field value. Their parts can be turned, mirrored, skewed or laid on a face.

### An asset's own text on its icon
- **Binding a text param:** a category's icon can declare one (`param label (text)"Label"`), and bind it under **Parameters** on the category's page to one of:
  - the asset's name;
  - its first code: its QR code, else its Micro QR, else its Code 128;
  - one of its fields.
- **Each asset is drawn with its own text** on its page, in lists, on scan pages, as an image (`?asset=`), on labels (live preview included), in scenes and through MCP.
- **Checked when saved:** a binding must name a param the icon has, and a text param takes text, a number param a number field.
- **Fallback:** an asset with no value, or whose icon won't draw with it, is drawn with the param's default.
- **API:** `PUT /api/v1/categories/{id}/icon/params` takes `name` or `code` in place of a field's ID. `resolved_icon` gains `texts` and `drawn`.

### More to draw with
- **Transforms:** parts can be turned in quarter-turns, mirrored, skewed or laid on a face, with `transform`, `turn` and `mirror-diagonal`.
- **Fonts and text:** a lexicon can define fonts, and icons can set words in them.
- **Fixed strokes:** a group can keep its strokes' width at any size. Labels print such a stroke enlarged with the icon, so a hairline still shows at a printer's resolution.
- **The editor's completion** offers all of the above, with the properties and values each takes.
- **Everywhere:** isolex's IR version 2 is drawn in the interface, in SVG and PNG images, on labels, in scenes and in the live preview, matching isolex's own drawing.

### Upgrading
- **Migration:** `040` runs when the service starts.
- **Compiler:** the embedded isolex compiler is now 0.5.0, pinned by checksum. Its module is now a release attachment on isolex's forge rather than a package, so a build from source fetches it from there (`tools/isolex/fetch.sh`).
- **Icons are rebuilt once at startup.** Builds now keep the source files they were made from, so the server makes each existing build again the first time it starts. Until then, and if the new compiler refuses a published source, the previous build stays in use, so nothing goes blank.
- **Version 1 IR is still read**, so builds from earlier releases keep drawing.
