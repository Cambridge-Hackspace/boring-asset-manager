## A fix for assistants reading fields

This release fixes MCP tools that answered with an error instead of their result.

### Fixed
- **`get_category` works on every category.** On a category with a select field, it failed with `validating tool output: … has type "object", want one of "null, array"`. A select field's choices are an object, and the tool's schema took them for a list.
- **The same fix covers every tool answering raw JSON:** a field's options, a report's spec, a channel's options and an icon's compiled IR. A tool taking raw JSON as an argument now accepts any JSON value too.

### Upgrading
- Nothing to do: no migration, and no change to the API or the web interface.
