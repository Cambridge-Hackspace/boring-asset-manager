## Copy a label template

This release lets you start a label template from one you already have.

### Added
- **Duplicate** on the list of label templates, beside **Delete**. It copies a template as saved, names the copy *… copy*, and opens it in the editor.
- **Save as…** in the editor, on the arrow beside **Save**. It saves what is in the editor, unsaved changes too, as a new template under the name you give, and opens it. The template you started from stays as it was last saved.
- Categories that use the original template keep using it; nothing is pointed at the copy.

### For people's own assistants
- `POST /api/v1/templates/{id}/clone` copies a template, with an optional `name`. It needs `templates.manage`.
- A new MCP tool, `clone_template`, does the same.

### Upgrading
- Nothing to do: no migration, and no change to existing API answers.
